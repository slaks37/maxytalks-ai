# MaxyTalks — How AI Can Really Help You

20-screen interactive web-based teaching material branded for MaxyTalks.

## Live demo
Open `index.html` in a browser. Slides support keyboard arrows, Space, Home, End, and N for presenter notes. Includes 4D framework, Job Brief Builder, connection simulations, and activities. Connector examples are locally simulated; no login or real inbox data is accessed.

## Deploy
Static HTML/CSS/JavaScript — no build step and no secrets. Import GitHub repository into Vercel. Framework Preset: Other, Root Directory: `/`, output directory: project root. The `vercel.json` file adds response headers and clean URLs.
